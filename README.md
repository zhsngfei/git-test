# 未至

未至是一款旅行前的文化触点推荐应用。用户输入目的地城市和阅读/观影偏好后，获得与该城市相关的书籍、电影或剧集推荐，以及作品中涉及的景点触点。

## 当前内容

- `DESIGN.md`：给 Stitch 或 UI 生成工具使用的设计说明。
- `prototype/`：手机端静态 UI 原型，可直接打开 `prototype/index.html` 预览。
- `tools/`：历史辅助脚本，目前保留 Word PRD 生成脚本以便追溯。
- `artifacts/`：历史生成产物和 QA 截图。

## 预览

直接打开：

```text
prototype/index.html
```

当前原型是 iPhone 16 尺寸的手机 App 预览，包含探索、收藏、我的三个主入口，以及作品详情、景点触点、收藏和想读/想看交互。
