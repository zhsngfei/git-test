# 未至 UI/UX 设计说明

## 目标

本阶段产出未至第一版核心页面的中保真 UI/UX 稿，用于确认信息架构、页面节奏、视觉方向和关键交互，再继续实现城市结果页等前端代码。

本稿不是生产代码，不替代 `weizhi-app/frontend` 中的正式页面实现。

## 设计原则

- 移动优先，按手机单列体验设计。
- 视觉方向为现代城市笔记感。
- 浅色、干净、轻盈、有人文气质。
- 不做旧报纸、旧书、泛黄纸张、强复古纹理。
- 不参考外部截图视觉。
- 图片区域要稳定，有明确比例。
- 文案短句化，避免大段城市介绍。
- 操作区清晰，收藏行为轻但可见。
- 触控目标不小于 44px。
- 主要正文不小于 16px。

## 页面范围

本阶段覆盖五个核心页面：

1. 首页
2. 城市结果页
3. 作品详情页
4. 地点详情页
5. 收藏准备册

## 首页

首页需要同时完成两件事：

- 让用户立刻知道可以搜索城市。
- 让用户感受到这不是普通旅行工具，而是一份出发前城市笔记。

首屏包含：

- 品牌名“未至”。
- 品牌语“出发之前，先进入一座城市”。
- 城市搜索框。
- 主题气质标签。
- 精选城市主视觉卡片。

首页下方包含：

- 精选城市入口。
- 主题卡片入口。
- 少量热门作品或地点触点。

## 城市结果页

城市结果页不是普通结果列表，而是按主题气质组织的城市笔记。

页面结构：

- 城市标题与城市气质短句。
- 当前筛选条件。
- 内容类型筛选：全部、书籍、电影。
- 主题气质分组。
- 每组第一个作品为重点大卡。
- 其他作品为轻量卡。

## 作品详情页

作品详情页需要同时解释：

- 为什么值得在出发前读/看。
- 它如何连接这座城市。
- 它关联哪些地点触点。

页面结构：

- 作品大图。
- 作品名、类型、作者/导演。
- 简短简介。
- 推荐理由。
- 城市关系。
- 地点触点列表。
- 收藏按钮。

## 地点详情页

地点详情页是文化触点页，不是旅游攻略页。

页面结构：

- 地点大图。
- 地点名称和所属城市。
- 简短介绍。
- 它在作品中的意义。
- 关联作品入口。
- 收藏地点按钮。

不展示：

- 路线。
- 地图。
- 开放时间。
- 门票。
- 附近餐厅。

## 收藏准备册

收藏页按城市组织，不按普通收藏时间线组织。

页面结构：

- 页面标题“出发前准备册”。
- 城市分组卡片。
- 每个城市显示收藏作品数和地点数。
- 进入城市后分为“作品”和“地点”两个 tab。

## 待确认点

- 首页主视觉是否偏“城市照片感”而不是插画感。
- 城市结果页分组标题是否足够有“主题气质”。
- 卡片圆角、阴影和留白是否符合现代城市笔记感。
- 收藏页是否需要在第一版就加入底部导航。
